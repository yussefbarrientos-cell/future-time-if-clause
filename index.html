Grammar Rule 2.9

Future + Time or If Clause

Rule 1: Time / If Clause First (Needs Comma)

Time / If Clause (Simple Present) , Main Clause (Future)

Example: When I retire, I am going to start a new hobby.

Rule 2: Main Clause First (NO Comma)

Main Clause (Future) Time / If Clause (Simple Present)

Example: I will continue to work if I am healthy.

be going to
Plans & intentions decided earlier.
"He is going to drive to the airport."
will / 'll
Instant decisions, promises & predictions.
"I'll let you know later today."
Present Continuous
Fixed arrangements with dates/times.
"They're coming on Sunday."
